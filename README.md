# 🔷 jQuery

**jQuery** is a JavaScript library designed to simplify HTML DOM tree traversal and manipulation, as well as event handling, CSS animations, and Ajax. It is free, open-source software using the permissive MIT License. As of October 2026, jQuery is used by 65.3% of the 10 million most popular websites.
